# PianoPond

MIDI 鍵盤で和音を弾く、落ちものタイプの音ゲーです。
音ゲーにしてありますが、真の目的は「好きな曲をコード弾きできるようになる練習ツール」です。
上から落ちてくるコードネームに合わせて、左手でベース、右手でコードを押さえます。
ドラムとベースの伴奏は自動で鳴り、ピアノの音はブラウザが合成します。

- ブラウザとWebサーバだけで動きます。ビルド不要、依存パッケージなし
- 譜面はコード進行で書きます(`C | Am F | G7`)。細かい音符を打ち込む必要はありません
- 譜面の自作、JSON の書き出し・読み込みができます
- MIDI 鍵盤はドからドまで2オクターブ以上あるものを用意してください
- MIDI 鍵盤がなくても PC のキーボードで遊べる機能を気休め程度につけています

## Web

https://aike.github.io/pianopond/

## 動作環境

- Chrome または Edge(Web MIDI API を使うため)。Firefox と Safari では MIDI 鍵盤が使えません。
- 2 オクターブ以上の MIDI 鍵盤(C3〜C5 を使います。最低音は設定で C2 / C3 / C4 から選べます)。
- Python 3(開発用の簡易サーバに使います。別の静的サーバでも構いません)。

## ローカル起動

```
git clone https://github.com/aike/pianopond.git
cd pianopond
python -m http.server 8080
```

ブラウザで http://localhost:8080/ を開きます。
初回に MIDI 機器へのアクセス許可を求められるので「許可」してください。
`file://` で直接開くと ES モジュールと Web MIDI が動かないので、必ず http サーバ経由で開いてください。
httpサーバは必ずしもpythonである必要はありません。

## 遊び方

1. 「曲選択」でテンポ(原曲の 10%〜150%、10% 刻み)を選び、譜面の「プレイ」を押します。
   テンポが速いほどスコア倍率が上がります(120% なら ×1.2)。精度とランクはテンポに影響されません。
2. 1 小節のカウントイン(クリック音)の後、伴奏(ドラムとベース)が始まります。
3. 上から落ちてくる和音が判定線に重なった瞬間に、表示された鍵を全部押します。
   オレンジのノートが左手のベース、水色のノートが右手のコードです。
   コードネームは画面上部とノートの上に表示されます。
   画面上部の「いま弾く」が切り替わると同時に、鍵盤上でその和音の鍵が薄く光ります。
   和音を弾いた後も鍵を押さえている間は表示が切り替わらず、全部の鍵を離した時点で次の和音に切り替わります。
4. 判定は和音単位です。必要な鍵が全部そろった瞬間の時刻で判定します。
   Perfect は ±50 ms、Good は ±120 ms、それ以外は Miss。余分な鍵を押しても減点はありません。
5. 曲が終わるとリザルト画面に移ります。Esc で途中終了できます。

## 設定

- MIDI 入力: 既定の「すべての入力」では、つながっているどの MIDI 機器からでも弾けます。特定の機器に限定することもできます。
  その下の「受信モニタ」には、鍵盤を押すたびに届いたメッセージ(ポート名、ノート、ベロシティ、生データ)が表示されるので、
  反応しないときはまずここで機器からメッセージが届いているか確認してください。
- 鍵盤の最低音: お使いの鍵盤の一番左のドが C2 / C3 / C4 のどれかを選びます。
  設定画面で鍵を押すと、その音名が表示されるので確認に使えます。
- 判定オフセット: いつも「早い」と出るなら負の値、「遅い」と出るなら正の値にします。
- ノート落下速度、ピアノ音量、伴奏音量。音量を一番下(ミュート)にすると、その音源は完全に鳴らなくなります。

設定と自作譜面はブラウザの localStorage に保存されます。サーバには何も送りません。

### MIDI 鍵盤が反応しないとき

1. 設定画面の「受信モニタ」を見ながら鍵盤を押します。更新されれば受信はできています(範囲外やミュートの注意が出ていないか確認してください)。
2. 更新されない場合は、画面上部の MIDI 状態を確認します。「拒否されました」なら、アドレスバー左のアイコン → サイトの設定 → 「MIDI デバイス」を「許可」にして再読み込みしてください。
3. それでも見つからない場合は、他のアプリ(DAW など)が機器を占有していないか確認し、機器を挿し直してから「再検索」を押してください。

## 譜面の作り方

「譜面エディタ」で、タイトル、BPM、拍子、リズム種別、コード進行を入力して保存します。
「試奏」でそのまま遊べます。JSON の書き出し、読み込みもできます。

### 自作譜面の保存場所

自作譜面は、ファイルやサーバではなく、ブラウザの localStorage に保存されます。
キーは `pianopond.charts`(設定は `pianopond.settings`)で、保存した譜面全部が 1 つの JSON 配列として入っています。
Chrome なら DevTools(F12)→ Application → Local Storage で中身を確認できます。

localStorage の性質上、次の点に注意してください。

- 保存先はサイト(オリジン)ごと、ブラウザ・プロファイルごとです。
  https://aike.github.io/pianopond/ と http://localhost:8080/ で作った譜面は別々に保存され、互いには見えません。
  他の PC、他のブラウザ、同じブラウザの別プロファイルにも同期されません。
- ブラウザの閲覧データ(サイトデータ、Cookie など)を削除すると、譜面も消えます。
  シークレットウィンドウでは、ウィンドウを閉じた時点で消えます。
- 保存できる量はブラウザの localStorage の上限(通常 5 MB 程度)までです。コード進行だけなので、ふつうの使い方で足りなくなることはありません。

残しておきたい譜面は、譜面エディタの「書き出し」で JSON ファイルとしてダウンロードしておき、
必要なときに「読み込み」で戻してください。別の PC やブラウザに持っていくときも同じ手順です。

リズム種別は伴奏(ドラムとベース)のパターンを決めます。
和音はコードが変わるタイミングで 1 回弾きます。

コード進行の文法:

```
C | Am F | G:3 C:1 | Dm7 G7   // コメント
Cmaj7 | F[53,57,60] | % | G/B
```

- 小節は `|` または改行で区切ります。
- 小節内に複数のコードを空白で並べると、拍を等分します(4/4 で `Am F` なら 2 拍ずつ)。
- `G:3` のように `:拍数` で拍数を明示できます。
- `%` は直前のコードの繰り返しです。
- 押す鍵は「左手: ベース 1 音 + 右手: コードの密集和音」の形で自動的に決まります。
  ベースはルート(分数コードならその指定音)を C3〜B3 に置き、右手はその上で C5 までに収まる転回形のうち、
  直前の和音から指の移動が少ないものを選びます。
- `F[53,57,60]` のように MIDI ノート番号(C3=48 基準)で押す鍵を固定できます。一番低い音が左手のベースになります。
- 対応コード: メジャー, m, 7, maj7, m7, mM7, dim, dim7, m7b5, aug, aug7, sus2, sus4, 7sus4, 6, m6, 69, add9, madd9, 9, m9, maj9, 7b9, 7#9, 7b5, 5, 分数コード(C/E)。

譜面 JSON の形式:

```json
{
  "title": "マイ進行",
  "bpm": 120,
  "beatsPerBar": 4,
  "rhythm": "8beat",
  "progression": [
    { "chord": "C", "beats": 4 },
    { "chord": "G", "beats": 2 },
    { "chord": "Am", "beats": 2, "notes": [57, 60, 64] }
  ]
}
```

`rhythm` は `whole` / `4beat` / `8beat` / `16beat` / `shuffle` のいずれかです。

## 開発

```
npm test        # ブラウザ不要部分のテスト (node test/run.js)
npm start       # python -m http.server 8080
```

構成:

```
index.html, style.css     画面
src/main.js               画面遷移と結線
src/midi.js               Web MIDI 入力、PC キーボード代替
src/storage.js            設定と自作譜面の保存
src/audio/                ピアノ・ドラム・ベースの合成音源、音量、先読みスケジューラ
src/chart/                コード名解析、ボイシング、リズム種別、譜面形式、タイムライン生成
src/game/engine.js        伴奏予約、判定、スコア
src/ui/lanes.js           レーンと鍵盤の Canvas 描画
data/charts.js            内蔵譜面
test/run.js               ブラウザ不要部分のテスト
```

### サンプル曲(内蔵譜面)

`data/charts.js` に含まれる内蔵譜面は、BPM、拍子、リズム種別、コード進行だけで構成されており、
旋律や歌詞、音源は含みません。

- 「カノン進行」「1-6-4-5 進行」「王道進行」「小室進行」「12 小節ブルース」「ツーファイブワン」は、
  楽曲に依存しない一般的なコード進行です。
- 「きらきら星」「歓喜の歌」「ハッピーバースデー」「アメイジング・グレイス」は、
  原曲の著作権保護期間が満了しパブリックドメインとなっている楽曲のコード進行を、本プロジェクトで独自に採譜したものです。
  ハッピーバースデーは、旋律の元となった "Good Morning to All"(1893 年)がパブリックドメインであり、
  歌詞も 2016 年の米国での和解によりパブリックドメインと確認されています(本譜面に歌詞は含まれません)。
